# 中文 Hero 文字排版审查

审查范围：首页 Hero 内容卡的中文状态；桌面视口 1440 × 900，手机视口 390 × 844。

## 总体结论

字体、字号、行高、卡片留白和按钮排布整体健康。主要问题集中在中文断行：桌面说明文字出现仅有“国。”的孤行，标题在桌面和手机端都把“都是”拆到两行。

## 证据与步骤

1. 桌面中文 Hero — 需要调整
   - 截图：`01-hero-desktop-zh.png`
   - 标题为 52px / 59.8px，共两行：`每一站，都` / `是故事。`
   - 说明为 23px / 32.2px，共两行，第二行只有 `国。`，形成明显孤行。
   - 卡片上下留白和按钮位置平衡。

2. 手机中文 Hero — 基本健康
   - 截图：`02-hero-mobile-zh.png`
   - 标题为 34px / 39.1px，共两行：`每一站，都` / `是故事。`
   - 说明自然断为 `一辆 Model Y，沿着超级充电网络` / `驶过美国。`，阅读节奏良好。
   - 两个按钮保持同一行，触控尺寸和标签可读性良好。

## 建议

1. 中文标题使用语言专属断行，建议为 `每一站，` / `都是故事。`，避免拆开“都是”。
2. 桌面说明文字固定在“驶过美国。”之前换行，或使用中文专属宽度与更稳健的断行规则，避免 `国。` 单独成行。
3. 保留现有字号、行高、卡片高度和按钮尺寸；这些部分无需缩小。
